# 🐧 OverTheWire Bandit Writeup

Este repositorio contiene mi progreso y documentación resolviendo la serie de retos **Bandit** de [OverTheWire](https://overthewire.org/wargames/bandit/).

Bandit es una plataforma diseñada para aprender los fundamentos de Linux, navegación en sistemas, procesamiento de texto y técnicas básicas de ciberseguridad a través de retos prácticos.

---

## 🎯 Objetivo

El objetivo de este proyecto es:

- Aprender y reforzar conocimientos de Linux
- Mejorar habilidades en la terminal
- Comprender herramientas clave utilizadas en ciberseguridad
- Documentar el proceso de aprendizaje de forma estructurada

---

## 📂 Estructura del repositorio

El contenido está organizado por bloques de niveles:

```
├── level-0-10.md
├── level-10-20.md
├── level-20-30.md
└── level-30-34.md
```

---

Cada archivo incluye:
- Objetivo de cada nivel
- Enfoque de resolución
- Comandos utilizados
- Explicación detallada
- Aprendizajes clave

---

## 🧠 Habilidades desarrolladas

Durante estos niveles se practican conceptos como:

- Navegación en sistemas Linux (`ls`, `cd`, `pwd`)
- Manipulación de archivos (`cat`, `file`, `strings`)
- Búsqueda avanzada (`find`, `grep`)
- Procesamiento de texto (`sort`, `uniq`)
- Uso de pipes (`|`)
- Manejo de permisos y estructura del sistema
- Resolución de problemas en entornos reales

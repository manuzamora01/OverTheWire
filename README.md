# 📑 Cybersecurity Labs & Writeups

Bienvenido a mi cuaderno de bitácora técnica enfocado en seguridad informática, hacking ético y resolución de retos de tipo **CTF (Capture The Flag)**. El objetivo de este espacio es documentar los procesos de explotación, análisis de sistemas y escalada de privilegios.

## 🏁 Plataformas en Desarrollo

### 🥷 OverTheWire: Bandit
Laboratorios enfocados en la seguridad de sistemas operativos basados en Linux, administración de servidores mediante SSH, gestión de permisos y flujos de datos en terminal (`Bash`).
* [Ir al Nivel 0 -> 10](./bandit/level-0-10.md)

### 🎯 PicoCTF
Retos de seguridad en diversas categorías como explotación web, criptografía, ingeniería inversa y análisis forense.
* [The Beginner's Guide to the Challenge Library](./picoCTF/The_Beginner's_Guide_to_the_Challenge_Library/README.md)
